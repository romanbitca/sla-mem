## Needs a person before the first release

1. 👤 **Real sign-in** to the 9H workspace on macOS and on Windows, including whichever method the
   workspace uses. Try Google SSO explicitly (PLAN §2.4). If Google refuses the embedded window,
   the "Sign in with email" code and **Advanced → paste session cookie** paths are the fallback.
2. 👤 **First real sync:** message counts look plausible, threads are complete, a second sync
   right after adds nothing. _(Done on 2026-09-22: 7,547 messages from 111 conversations.)_ Still
   to see on real Slack: the log of the next sync says "Reading N of 111 conversations", not
   "Slack’s activity summary is unavailable" (the summary is an undocumented call; without it
   syncs still work, just slower).
3. 👤 **Clean-machine installs** on macOS and Windows, by someone who didn't build the app,
   following only [INSTALL.md](INSTALL.md).
4. 👤 **First release:** the repository is public since 2026-09-22, so releases can be seen by
   colleagues and by the update check. Publish one (README → Releasing), then confirm an older
   installed copy shows the update banner and that the upgrade keeps the archive.
5. 👤 **Read your own archive** and compare a sample of tricky messages with Slack (Stage 4).
